任务：每天 0 点后（00:00–00:10），为本机「工作台」应用**预生成当天的简报缓存**。
这是「每日一刷」，不是实时刷新：夜间批处理，用户在睡觉，**不要弹任何窗口、
不要发通知**，做完安静收工。

背景：「工作台」是桌面小应用，白天用户开机才启动，0 点时它多半没在运行。
所以本任务**不走它的 HTTP 接口**，而是直接用 exe 的无窗口预生成模式。

步骤：

1. 运行（同步等它退出，通常 1–3 分钟）：
   "%LOCALAPPDATA%\Programs\Workbench\Workbench.exe" --prefetch
   - 无窗口模式：不绑端口、不开界面，只抓新闻 + 调模型生成
     「今天日期」的简报缓存，写完自动退出。
   - 退出码 0 = 正常完成（哪怕没抓到新闻也算跑完，应用明早会自己重试）。

2. 校验（只读，绝不修改文件）：
   读取 %APPDATA%\Workbench\cache\daily-<今天日期 YYYY-MM-DD>.json
   - 文件存在且是合法 JSON；
   - generatedAt 的日期部分是今天；
   - news.items 非空、fields.quote 非空。

3. 汇报（写进任务结果即可）：
   - 成功 → 报告新闻条数 + 今日一句话全文。
   - 失败 → 重跑第 1 步重试 1 次；仍失败就如实记录原因。
     应用明早打开时会自检缓存并兜底重建，所以单次失败不算事故。

禁止事项：
- 不要调 127.0.0.1:39217 的任何接口，也不要尝试启动工作台的可视窗口——
  那是明早用户自己做的事。
- 不要动 cache 目录里的其他文件，不要碰 config.json。
- 模型 API Key 在本机配置里，exe 自己会用，不要索要、不要传输。
- 不要在 23:50 前后跑——那会生成「昨天日期」的缓存，位置对不上。
  必须落在 0 点之后、当天开始之后。
